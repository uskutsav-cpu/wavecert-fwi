`adapter.py` connects the existing reviewed main-package APIs to five candidate

retains the strongest implemented incremental source/receiver route and paid
accepted LU/field reuse. GMRES pays the same coarse-Galerkin initializer and
norm-free inverse action, checks every column's true residual, and fails closed
with retained reports. It is not a different approximate-merit oracle.

The uncertified arm performs no stability SVD/eigenproblem/bound work. The
certified arm accumulates its local and dispatch ledgers in addition to the
stability engine's cumulative counts; it does not add the engine's query receipt
again. Both arms have independent policy-owned factories, and synthetic tests
check identical field hashes, gradient hashes and bitwise directions for both
the forward-field and receiver-map routes, including repeated receivers.

approximate gradient establishes true stationarity. The certificate is a
