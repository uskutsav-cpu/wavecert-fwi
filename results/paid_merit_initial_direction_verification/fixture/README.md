# Eight initial-direction witnesses — source-only candidate

This narrow software verification fills one specific evidence gap: the360-run
compact trajectories retain hashes of intermediate directions/gradients, so their
archived true-directional-derivative scalars cannot be independently replayed.
It recomputes exactly one certified cached-merit query at each of the same eight
original initial models, retaining raw vectors and fields. It does **not** replay
all360intermediate-query results or extend their scope retroactively.

No code in this candidate has been imported, parsed, tested or executed while the
timed benchmark is live. No project arrays or benchmark outcomes were inspected.
The candidate stays outside the repository and does not alter source9f or the
pinned807 objective auditor. Root must independently verify the timing process
terminal, review/freeze these bytes, validate the software, then decide execution.

The production side calls the actual frozen certified adapter once per model,
with49grid,rank64,four repairs and unchanged24source-frequency blocks. A small
private adapter binding wrapper retains references to the real certificate input
snapshot/missing fields and returns the unchanged certificate object. It restores
the original binding in finally. No production file or algorithm is edited.
This observational wrapper is disclosed and supplies no timing evidence.

The independent side uses the pinned807 separate direct-graph operator assembly,
explicit bilinear truth and own synthetic observations. It solves its own forward
states and physical conjugate-transpose adjoints, then forms a true discrete
survey gradient. It shares NumPy/SciPy/SuperLU with the production dependency
stack; equation assembly/data generation are separate, linear algebra libraries
are not. Constructor truth/initial-Phi work and fresh gradient state/adjoint work
are recorded separately.

Each case saves raw initial/truth/model geometry, approximate gradient, direction,
independent true gradient, all four production cached/missing fields and receiver
data/residual arrays, and independent state/adjoint/data/forcing arrays. Full
original scalar certificate, stability/error-component and directional-bound-term
receipts, proposal diagnostics, snapshots, source hashes and raw-array/file hashes
are retained. Numerical abstentions and unavailable directions remain unknown;
partial failed cases and every one of the eight planned slots remain explicit.

The second script uses only NumPy and saved arrays. It independently applies the
stencil, checks state/adjoint residuals and snapshot/input field bindings, rebuilds
physical gradient contractions and dot products, and checks sums of saved scalar
bound terms. It runs no solver and imports no production module. It does not
independently reconstruct coarse stability constants or prove a FP enclosure.
Both literal bound coverage and the historical helper's extra numerical allowance
are reported separately; a negative true DD is ordinary-FP evidence only.

The JSON protocol fixes agreement tolerances before any witness outcome. Failed
verification must be preserved/investigated without quiet tolerance changes. The
runner saves a new outer directory only; the raw replayer writes a new report
outside that directory. Neither runs an optimizer, chooses models/ranks/settings,
compares performance, creates new geology, or supplies a student final design.


of student ownership. No paper/abstract/conclusions are produced.
