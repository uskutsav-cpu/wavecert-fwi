# BP2004 acquisition staging: no velocity payload fetched

`protocol.json` was registered before any BP velocity-payload inspection. The
24,615-byte original publisher PDF is documentation only; its SHA256 is pinned
in the collector and `documentation_manifest.json`. This staging contains no
BP velocity array, model evaluation, plot or timing result.

The three fixed centers are `(z,x)=(.25,.20),(.50,.50),(.75,.80)`. Each retains
a 192-by-192 native sample window at 6.25 m by 12.5 m, then `raw[::2,::1]` produces
a 96-by-192 isotropic 12.5 m view. The six arrays inherit ONE BP2004 composite
synthetic ancestor. Source indices and physical coordinates remain recorded;
no interpolation, clipping or post-inspection choice is permitted.

The expected big-endian SEG-Y layout is 5395 traces of 1911 samples, format 1
(IBM32) or 5 (IEEE32), with no extended text headers. Every velocity is decoded
and checked finite/positive, but only the predetermined crops are retained.
The parser never allocates a full decoded velocity matrix. It streams one
gzip member, checks complete CRC32/ISIZE and layout, and rejects extra members,
trailing data, malformed headers, truncated responses and byte-cap violations.
All original SEG-Y headers are preserved losslessly in the metadata receipt.

The official compressed URL and expected 19,533,256 bytes/ETag came from the
metadata audit. An ETag is not a SHA256: the actual full compressed and
uncompressed SHA256 values will be measured only during an approved fetch.
The archive/full decoded model never goes to local disk. Output publication is
a new-directory rename after all checks; existing evidence is never overwritten.

Run the default CLI to print protocol/source hashes without network access:

```sh
python collect_bp2004.py
```

After root review/freezing, the explicit acquisition command will require
`--fetch --output DIRECTORY --expected-protocol-sha256 HASH
--expected-source-sha256 HASH`. Do not run it before approval. Synthetic tests
use generated bytes and mocked HTTP responses only:

```sh
python -m pytest -q -W error -p no:cacheprovider test_collect_bp2004.py
```
