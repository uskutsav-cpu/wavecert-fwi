# SEG/EAGE 3-D Overthrust model: official distribution CD1 (Overthrust_3D_CD1.tar.gz)

This record re-hosts files of the SEG open-data distribution of this model. The bucket that served
them (`https://s3.amazonaws.com/open.source.geoscience/open_data/seg_eage_models_cd/Overthrust_3D_CD1.tar.gz`) stopped serving anonymous downloads in 2026; the data file here is byte-identical to the copy
it served (SHA-256 below).

## Files

| file | bytes | SHA-256 |
|---|---|---|
| `Overthrust_3D_CD1.tar.gz` | 174960038 | `7c10f9aa29beab25a40fc0cccede6631284bc2fa7e45a3511dbdceba8f5cf246` |

`Overthrust_3D_CD1.tar.gz` holds the 3-D velocity grid (`3-D_Overthrust_Model_Disk1/3D-Velocity-Grid/overthrust.vites`: raw big-endian IEEE float32, 801 x 801 x 187 cells at 25 m, m/s, x fastest), the model database and documentation of distribution CD 1, the SEG/EAGE 3-D Modeling Series No. 1 booklet, and the README and LICENSE of the SEG open-data release.

Every file can be downloaded on its own, e.g. `wget https://zenodo.org/records/<record>/files/Overthrust_3D_CD1.tar.gz`.
