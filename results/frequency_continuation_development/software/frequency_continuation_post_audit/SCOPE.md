# Stored-scalar audit scope

This is an AI-authored software integrity and eligibility check for one explicitly
named, completed 96-run engineering cohort. It is not a student research design,
new inversion method, independent human review, or physical acceptance test.
The numerical criteria in `criteria.json` remain the original pre-outcome bytes.
No producer outcomes or corpus arrays were opened while writing or testing this
auditor. Controls use manufactured scalar records and small manufactured arrays.

The default command prints metadata only. Execution requires an explicit root GO,
fresh outer output, the frozen auditor/criteria/driver/protocol SHA256 values,
and a hashed root terminal observation recording the actual producer exit code.
The root execution wrapper must retain the exact command, actual exit and full
stdout/stderr, including exceptions before a report can be written. This auditor
does not promise a durable report after an I/O or unexpected reference-load
exception; its source, root CLI log and first failure must remain preserved.
An unknown exit is refused rather than inferred from process absence. The pinned
driver must have returned 0 when all its offline audits passed, or 2 when its
completed cohort reports an offline audit failure. A different exit, missing
complete receipt, source mismatch, schedule mismatch or manifest mismatch prevents
reference/model decoding and retains all 96 rows as noncredit metadata.

After valid preflight, the auditor hashes artifacts before decoding them. It
checks the 24 case/repetition quadruples, 32 case/method groups, actual caller
return times, both strict timing gates, direct common starting models, available
data fingerprints, stage chronology, recorded common-eight receipt headers,
source bindings, separate preparation costs, and final snapshots counted once
per unique serialized owner label. Unknown work remains unknown rather than zero.
It recomputes scalar model errors with `math.fsum` and scalar square roots against
an explicit half-cell bilinear reconstruction of the original 24-by-24 velocity
field. The generic SciPy reflect-Gaussian initial filter and NumPy input decoding
are shared dependencies and are disclosed. Fixed quality tolerances are inherited
from the earlier independent saved-model checker.

Each target is a ratio at the actual returned model, not a first-hit event or a
stopping experiment. A late return or invalid inner result cannot receive credit.
Failed, late, missing and interrupted rows remain in the full denominators.
Medians require all three eligible repetitions; no successful-only median or
winner is produced. Any independent inconsistency disables verified credit for
the cohort while recorded statuses and negative results remain visible.

The compact producer records cannot authenticate opaque native owner tokens or
replay per-stage first/current native headers, omitted scalar events, intermediate
vectors or PDE solves. The auditor checks retained SHA chronology and the pinned
source's enforcement of those bindings. A stream hash is recomputed only when all
its records are retained. Embedded807 objective checks are separately generated
producer evidence, not a new PDE execution by this auditor. Global elapsed ages
and nested cost snapshots are never added as independent durations or work.

The first cohort's external interruption has an unknown process exit and no
complete receipt, as reported by root. This full-cohort auditor has not read that
cohort and does not authorize a partial quality analysis. See the separate
`PARTIAL_COHORT_SCOPE_ADDENDUM.json`; a later full cohort is a separately named
cohort, with all first-cohort failure denominators preserved externally.

All conclusions are conditional ordinary-floating-point software checks over
eight reused, correlated inputs on a shared machine. Physical acceptance,
independent-site counts, p-values, recovery guarantees, novelty, student ownership
and completion of scientific goals remain unestablished.
