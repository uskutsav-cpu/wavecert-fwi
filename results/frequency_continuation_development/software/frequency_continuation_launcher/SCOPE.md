This stdlib launcher records an immutable dispatch request, exact registration bytes/hash, detached supervisor PID/session/start, producer command/PID/start, and its actual observed wait return code, including a negative signal code only when observed. Supervisor and producer have their own sessions, standard input is closed, and both logs go directly to files rather than a tool-host stdout pipe. Both use the original producer invocation's `-B -I -u` bytecode/isolation/unbuffered flags; inherited thread settings must equal the frozen protocol. The dispatch CLI returns promptly. There is no timeout, retry, resume, automatic second launch or numerical setting change. The producer's complete-receipt presence/hash is recorded, but process exit does not replace independent full-denominator/source/artifact/integrity review.

SIGINT, SIGTERM and SIGHUP delivered to the supervisor are recorded and forwarded to its known producer process group. A persistence/launch failure after child creation triggers best-effort stop/reap, preserving uncertainty if that itself fails. Detached sessions remove dependence on a long-running tool exec cell under ordinary parent closure; they cannot guarantee survival of external SIGKILL, forced descendant-tree termination, machine shutdown, disk failure or another process-management policy. An absent exit receipt still means unknown exit, never an invented success, signal or numerical failure. This is a local process-lifecycle engineering change, not a solver or experimental-method change.
