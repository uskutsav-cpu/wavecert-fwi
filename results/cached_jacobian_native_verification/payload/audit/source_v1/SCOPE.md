# Prospective cached-J retained-array audit, version1

This self-contained audit uses only the Python standard library. It imports no
NumPy, SciPy, production module, verifier or callback. It executes no solver,
optimizer, install, download, route, native child or permission/GO action. The
default CLI reads its own source/criteria metadata and ignores future packet
paths. No actual native packet was opened while this version was authored or
tested.

Execution is held until root explicitly authorizes an audit after a real terminal
observation. The CLI requires a fresh output outside the packet and auditor,
auditor/criteria hashes, root external observation/result hashes, and the exact
reviewed route source/manifest hashes. `--packet` points to the retained artifact
directory containing `artifact_inventory.json`, the route metadata and
`native/result.json`; it is not an archive downloader or extractor. Root supplies
an externally measured JSON with actual route `exit_code`, inventory SHA256,
route-result SHA256, experiment commit, repository and run-attempt fields. The
auditor cannot manufacture a child wait or establish remote authenticity itself.

Before any array decoding, metadata gates require known actual exit0 and owned
group cleanup, the actual14 stdlib lifecycle controls and44 component tests
without skips, registered public first-push context, exact frozen source and
runtime, explicit root GO/admission, complete stable byte inventory, no failure,
and the completed source-bound worker report. A failed, missing, interrupted or
unknown packet stays noncredit with zero NPZ decoding. Mandatory58 tests are
distinct from the source-derived160 public dispatches and their two expected
source/owner guard rejections.

The bounded reader adapts the stdlib NPY/NPZ parsing pattern from the SHA-pinned
`checkpoint_pilot23_comparison_candidate/independent_compare.py`. This copy adds
little-endian complex128 and the exact14-member schema. It accepts NPYv1/v2,
C-order float64/complex128 and ZIP_STORED only, checks actual bounded read lengths,
CRC via `zipfile`, exact dtype/shape/payload bytes and all finite values. The
archive cap is16MiB, payload cap8MiB and packet cap32MiB. It allows no pickle,
object/structured dtype, compression, duplicate/extra members or implicit cast.

Scalar reductions use `math.fsum` and `math.hypot`. The audit reconstructs the
960 complex residuals from retained native U and observations, checks their
real/imaginary packing and fixed initial normalization, compares cached and public
reference JVP/Jstar vectors, and recomputes the real-adjoint identity. It retains
both preset centered residual and objective FD outcomes. It compares all48 native
and48 complex-source covered row pairs using plain transpose and the exact source
amplitudes, with no conjugation. The inherited numeric tolerances stay unchanged;
the per-row audit rule is prospectively declared in criteria.json.

Final disjoint owner snapshots are checked once against96 LU,480 forward RHS,
48 tangent RHS,48 adjoint RHS and272 stability RHS. Map batches and actual native
policy counts remain separate; template/foreign zero-work prefixes are retained.
Dispatches, cache hits, mathematical operations and RHS are different counts.
Global age timestamps and nested snapshots are not added as independent work.

Only six of the20 receiver-map rows per frequency are retained. This audit does
not reconstruct the missing14 rows or the complete Jacobian. The old-operator
repeat vector, opaque owner identity and native method invocation cannot be
recreated from the arrays; their source-bound checks, events and prefixes are
verified as recorded evidence. The native selfRSS precedes final serialization;
parent RUSAGE_CHILDREN includes earlier controls and is not native-only memory.

The19 local controls use the standard library only. A manufactured full-shape

do not establish native API integration or reproduce actual remote results.
